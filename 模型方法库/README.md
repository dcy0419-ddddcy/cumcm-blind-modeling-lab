## 整理与盲解使用规则

1. 将教程按方法整理成独立方法卡，保留原始章节、链接、获取日期和上游版本信息；引用或改编时遵守来源许可，不将上游内容冒充原创。
2. 原始资料与审核后的盲解可用资料分开。筛查案例是否包含目标赛题或实质相同的题解，不能仅凭标题和年份判断。
3. 每张方法卡必须说明适用条件、禁用或失败条件、替代方法和验证方式，不因主教程收录某方法就默认它适合当前问题。
4. 示例代码在纳入可用库前需实际运行，记录依赖、命令、随机种子、预期结果与检查结果。尚未验证的内容明确标注“待验证”。
5. 每轮盲解开始前固定方法库版本，仅将审核后的本地资料及所需依赖放入单题工作区；盲解期间不得通过上述链接联网阅读或下载。
6. 揭晓后从优秀论文中提取的新方法与改进另行记录，不改写已冻结的盲解资料版本。

## 方法卡规范

方法库不应只是模型名称清单。每个方法建立一张独立方法卡，至少包含：

- 适用问题与识别信号
- 所需数据与前置条件
- 变量、假设和核心结构
- 标准求解步骤
- 参数估计与初始化
- 验证、诊断和敏感性分析
- 常见失败模式与反例
- 可替代方法及切换条件
- 最小可运行示例
- 适用过的题目与结果证据

建议按 `预测`、`分类`、`评价`、`优化`、`机理模型`、`图与网络`、`随机过程`、`仿真`、`数据处理` 和 `验证方法` 分类。
