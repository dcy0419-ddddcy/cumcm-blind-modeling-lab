**直接阅读：[官方论文阅读链接（2025 年，按 A/B/C 分类）](官方论文阅读链接.md)。** 所有逐篇链接集中在这一页，点击后直接从官网阅读论文。

学习时只产出抽象规则和反例，不复制原文段落、公式组织、图表造型、变量命名或特定题目的技术路线。每份学习笔记记录论文来源、年份、题型以及“为什么与当前目标题不构成答案泄露”。

进入某道题的盲解阶段后，不把本目录加入该题工作区。尤其是 2025 年 A、B、C 题：若模型已看过这里的对应论文，其后对这些题的作答应记录为“参考辅助训练”，不能再作为未接触当年论文的盲测成绩。
