# 盲解—复盘—迭代实验流程

## 阶段 0：实验登记

记录模型、推理强度、允许工具、方法库版本、非当年参考论文版本、题目盲号、开始时间和随机种子。一次实验只改变一个主要变量，便于比较。

验收条件：环境信息完整；当前工作区中不存在年份映射、当年论文、当年答案或网络检索产物。

## 阶段 1：赛前方法学习

让模型读取方法库和非目标年份优秀论文，产出的是“方法卡”和“写作规范卡”，不是对目标题目的方案。

每张方法卡至少包含：适用问题、数据要求、核心假设、算法步骤、诊断信号、失败模式、验证方式和替代方法。每张写作规范卡至少包含：摘要结构、术语习惯、图表规范、论证节奏、创新的呈现方式，以及不可模仿的具体内容。

## 阶段 2：盲题隔离

由管理员随机选择盲号并导出到独立工作区。模型只能看到 `题目.pdf`、匿名附件、提示词及自己产生的工作记录。

## 阶段 3：整体理解

先建立全题地图：题目背景、输入、输出、逐问目标、约束、评价指标、题间依赖、数据质量、符号单位和不确定性来源。此阶段不运行最终求解程序。

## 阶段 4：逐问循环

每一问执行以下闭环：

1. 重新表述本问，确认输入、输出和成功标准。
2. 至少提出两个结构上不同的候选方案；简单问题可说明为何一个基线已经足够。
3. 从可解释性、数据匹配、精度、稳定性、实现成本和与后问衔接等角度选型。
4. 明确变量、假设、目标函数、约束、算法、复杂度和参数来源。
5. 编码求解，并保存可复现入口。
6. 做量纲、边界、极端情况、基线、敏感性和数值稳定性检查。
7. 写入阶段记录；未通过验收则修订本问，不进入下一问。

## 阶段 5：全局校验与论文成稿

检查各问符号、单位、假设和数据口径是否一致；检查前问误差如何传播到后问；检查所有关键结论是否能由代码和输出复现。论文表达必须围绕问题、模型、证据和限制展开，避免堆砌模型名称。

## 阶段 6：冻结盲解版本

提交一个清晰的 Git 版本，记录实验配置、结果摘要、未解决问题和已知局限。冻结后不得修改该提交，只能在后续提交中追加复盘。

## 阶段 7：揭晓后多论文对照

一次性加载多篇当年优秀论文，先分别提取每篇论文的核心路线，再做横向比较，避免把第一篇论文误当作唯一标准答案。

差异必须分为：结果差异、定义差异、数据处理差异、模型结构差异、算法实现差异、验证差异和表达差异。判断自己的方案时使用证据，不因获奖论文采用不同方法就自动判定自己错误。

## 阶段 8：经验迭代

先更新本题经验，再审计总经验。总经验中的每条规则要带有适用范围、触发信号、执行动作、证据、反例和最近验证日期。未经跨题验证的发现标记为“候选经验”。

## 建议的对照实验

- 同一题、同一方法库，改变提示词版本。
- 同一题、同一提示词，改变模型或推理强度。
- 同一题比较“无参考论文预训练”和“仅非当年论文风格学习”。
- 同一题比较一次成稿与逐问阶段门流程。

比较指标包括：结果正确性、约束违反数、复现成功率、敏感性分析完整度、写作清晰度、创新有效性、人工修改时间和总成本。
