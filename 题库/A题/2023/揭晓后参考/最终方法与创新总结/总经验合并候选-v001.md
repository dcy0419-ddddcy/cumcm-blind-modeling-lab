# 总经验合并候选 v001

## 1. 审核边界

本文件只供管理员决定是否并入工作区外总经验库。本题三个小问和三篇同题论文不构成跨题验证，因此没有候选标记为“跨题验证支持”。满足项目规则的理由仅可能是“机制清楚且有反例边界”；管理员仍应去除目标题身份、核对与既有总经验是否重复，并决定是否入库。

## 3. 暂不合并的本题专属内容

- 特定光源半角、方向分布、圆柱接收器和N04有限终点；
- 特定额定功率、数值工作阈值、低存活100样本门槛；
- R027、Q3F013、塔位、镜数、尺寸、六组划分和具体改善比例；
- 本题异尺寸间距的 \(\max(w_i,w_j)+5\) 解释；
- A0165、A0127、A092的具体结果与页码。

这些内容应留在本题实例层，换题后从新题面和获准资料重新确定。

## 4. 管理员合并前检查

1. 搜索总经验库中是否已有同义规则，优先修订而非重复新增。
2. 检查触发情境、行动、反例和停止条件是否都能独立阅读。
3. 删除目标题答案、参数和论文身份，只保留必要机制。
4. 将证据状态准确标为“单题＋机制”，不得写“跨题验证”。
5. 记录合并前后文本、管理员审核结论及目标版本；本轮未执行这些操作。
