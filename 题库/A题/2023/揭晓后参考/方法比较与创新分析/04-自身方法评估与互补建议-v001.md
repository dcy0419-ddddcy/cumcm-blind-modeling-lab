# 自身方法评估与互补建议（v001）

## 1. 模型与评价部分

### 1.1 联合射线路径、三层能量与条件效率

**判断：建议保留。**

它把阴影、反射遮挡和有效接收放入同一条有限几何路径，净接收由实际接收事件决定，分项只在相应条件分母上解释。相较参考论文常见的“分别计算平均分量再相乘”，这种组织更容易发现重复计损、分母为零和平均口径错配。本题中重叠障碍、接收后障碍、三层能量代数及全场重建均通过检查。

它的证据边界必须保留：解析夹具与内部恒等式证明的是实现一致性，不能证明有限角光源、理想反射、接收边界和实体省略符合真实工程。下一次应在模型冻结前安排一个独立几何实现或公开基准构型，避免同一核心同时生成与验证答案。

### 1.2 N04分项记账

**判断：有条件保留。**

N04解决了“未接收射线没有自然反射终点时，反射路径遮挡的条件效率如何保持有限定义”的记账问题，使所有射线都能进入统一状态机。人工构型已经支持：只改变未接收光线终点，净接收量不变，但阴影遮挡与截断分量会改变。

它不应被描述为题面唯一物理分解，也不应进入净功率差异归因。若题目重点要求分项效率，优先寻找更直接的题意定义或同时报告联合接收量和N04分项敏感性。

### 1.3 随机采样与误差检查

**判断：建议保留，但调整资源分配。**

8批独立确认、原始和池化、整批删一诊断、相关前缀不重复计数、低存活影响筛查与共同随机数配对，都与“判定60 MW”和“识别不到1%的改进”直接相关。三篇参考论文均未给出同等级的不确定性组织。

不足是高精度评价太早占用预算会压缩设计探索。下一次应先用粗评价估计候选间差距和排名稳定性，只有当候选进入额定边界或差距接近数值分辨率时才提升精度。确认预算仍应事先预留。

### 1.4 内部一致性与物理正确性

**判断：建议优先改进证据措辞。**

本解答大部分文字已区分二者，但首次对照仍出现过把N04列入净功率差异原因的倾向，说明“模块定义清楚”容易被误读为“物理分解正确”。今后所有验证表应增加“能支持什么／不能支持什么”两列：

- 同射线筛选/穷举支持候选筛选不漏当前测试事件；
- 清单重建支持交付文件与计算输入一致；
- 独立批次支持抽样稳定性；
- 上述任何一项都不自动量化物理模型偏差。

## 2. 搜索与设计部分

### 2.1 Q2参数化、可行性修复和候选选择

**判断：参数化和修复机制建议保留；搜索范围建议优先扩展。**

Q2-A环带扇区表示保证候选能展开成完整清单，并允许镜数随裁剪变化。C22失败后按功率缺口修复，再在正余量候选中比较单位面积指标，实际产生R027，证明流程有效。

搜索限制也很明显：塔位只在少数南向位置试探，尺寸和相位候选少，没有系统释放环间距、扇区形状、局部增删和联合塔位变化。A0127的粗细网格与A092的按环表达都说明，本解答在“设计表达和候选覆盖”上还有较大空间。参考高指标不能量化这个空间，但足以把它列为最高优先级缺口。

### 2.2 搜索限制的收益与机会成本

| 限制 | 带来的收益 | 可能过早排除的设计 |
|---|---|---|
| 同心环/扇区 | 几何容易生成、检查和导出；维度低 | 非环形、局部扭曲、方位不对称布局 |
| 统一Q2尺寸和高度 | 与题意一致，搜索简单 | 不适用于Q3，但不是Q2缺陷 |
| Q3固定塔位、N和镜位 | 保住已确认可行基线，配对比较稳定 | 联合移动镜位、调整塔位、增删镜子带来的更大提升 |
| Q3仅6组 | 参数少、全场评价可负担 | 同一组内不同半径/方位的效率差异 |
| 宽不小于高 | 缩小搜索域、保持约定 | 若题面允许，可能排除高大于宽的有利镜面 |

搜索限制本身并非错误；问题在于论文和结论必须把“子空间内得到方案”与“原问题最优”分开。本解答做到了这一点，但在资源允许时应安排逐步放开，而不是把限制永久固化。

### 2.3 Q3的0.95%改善

**判断：这是可信的局部收益，不能作为搜索充分性证明。**

它证明固定R027镜位、塔位、镜数和6组划分下，减少一组镜高并小幅增加宽度能提高单位面积指标；新配对数据排除了普通抽样噪声作为主要解释。它没有证明逐镜异尺寸通常只带来1%左右收益，也没有证明固定布局接近最优。

第3问额定工作余量只有12.446 kW。数值规则下通过，但任何尚未量化的物理差异都可能大于这一余量。因此该设计适合展示“当前模型内的局部比值优化”，不适合作为工程裕度充分的方案。

### 2.4 保守评价器与搜索不足能否区分

**当前不能。**

第1问相对A0127、A092存在约4.7%—8.0%的年功率差（以参考值为分母），第2/3问的单位面积指标又明显低于A092。两类差距可能叠加：评价器更保守会整体降低功率，搜索子空间偏窄会降低可达到的目标。

要区分，至少需要以下一种证据：

1. 在同一组固定镜位上，用两种评价口径作受控模块替换；
2. 取得参考设计完整清单，用本评价器重评；
3. 用本评价器比较当前参数化与更宽设计表达，并保持确认规则相同。

现阶段不能把全部差距归咎于评价器，也不能断言全部来自搜索。

## 3. 工作流程部分

### 3.1 实际防止错误的环节

**建议保留：**

- C22独立确认失败被保留，防止把搜索估计误报为可行；
- 全点对几何和正式Excel读回，防止内存设计与提交清单不一致；
- 稳定镜身份与随机命名空间，防止并行调度或对象排序改变随机比较；
- 同射线筛选/穷举，防止加速筛选漏判；
- 真零、抽样零、NA和输入失败分开，防止静默补值；
- 失败代码、修订前文件和预算账本，防止事后重写历史。

这些证据比单纯“程序运行成功”更有价值，且确实改变过决策。

### 3.2 重复投入较多的环节

**建议优先压缩：**

- 多轮控制文档和哈希自引用修复占用了不少人工时间，虽不计光学预算，却分散了搜索注意力；
- 原型、全场、论文各阶段存在重复格式核验，可统一为一个只读交付检查器；
- Q2在尚无强可行候选时，对C22做了完整最高等级确认，确认失败虽有价值，但可先用更稳健的全60较精门禁减少失败概率；
- 页面排版和论文完善在数学结果尚未完全稳定前投入较多，下一题可延后到该问数值验收以后。

用户设定的阶段审批是任务约束，不能归为模型效率问题。可改进的是每个获准阶段内的执行顺序：先做改变决策的信息，再做证明文件完整的机械工作。

## 4. 四类结论

### 4.1 建议保留

1. 联合射线路径与三层能量主结构。
2. 约束、数值精度、额定判定、交付重建分状态管理。
3. 搜索共同随机数与冻结后新随机流确认。
4. 参数化生成后仍对实际清单做全量几何检查。
5. 失败和低存活事件留存，不用补0或删对象掩盖。

### 4.2 有条件保留

1. N04：保留为显式分项约定，同时报告其非唯一性。
2. 环带扇区布局：保留为初始可行子空间，随后允许局部扭曲或按环放开。
3. Q3分组：保留确定性、可复现分组，但组数和规则要由空间/效率结构驱动，并验证分组敏感性。
4. Monte Carlo主评价：当几何复杂且需要统一事件链时合适；简单构型先用确定性或解析方法。

### 4.3 建议优先验证或改进

1. 在同一评价器下比较“本解答6组固定布局”与“逐环尺寸/高度+有限局部镜位调整”。
2. 对Q1主要功率差做模块化消融，首先对齐A0127的光源离散、遮挡和截断口径。
3. 为额定边界设置搜索余量策略，使最终物理未确定性与数值余量在文字上明确分开。
4. 统一自动化证据生成，减少控制记录与自引用检查的重复成本。

### 4.4 证据不足，暂不评价

1. A092遗传算法相对环带规则本身的独立收益。
2. A092设计在本评价器下是否仍达到其报告单位面积指标。
3. A0127零净空是否来自最终清单精度、题意解释还是实际约束遗漏。
4. 本解答评价器相对真实物理究竟偏保守多少。

## 5. 互补建议

### M1：保留本解答评价/确认，采用A092式逐环表达

- **借鉴**：每一环或少量相邻环共享宽、高、安装高，并允许塔位和环间距联合调整。
- **保留**：联合射线、全障碍、几何全检、共同随机数和独立确认。
- **兼容性**：现有逐镜参数接口已经支持异尺寸；需把分组从6个固定空间组改为由环身份生成，并让缓存绑定新尺寸/位置。
- **预计改善**：扩大Q3设计表达，减少把不同物理环境镜子绑在同一组的损失。
- **代价**：变量数、几何失效和评价次数增加；可能降低额定余量。
- **最小实验**：固定R027镜位与塔位，用6组、按环10—20组、按环加方位分组三种表达，在同一低/较精随机流下比较；只对显著优于基线且有功率余量者确认。
- **放弃条件**：更细分组的改善不超过配对工作量，或可行候选比例/计算成本急剧恶化且局部合并不能恢复。

### M2：保留严格约束核验，采用A0127式生成约束

- **借鉴**：用环内角间隔、相邻环相位和环间距在生成阶段减少不可行候选。
- **保留**：最终仍对展开清单做全点对、场界、禁布区和净空检查。
- **兼容性**：与Q2-A同属环带路线，主要需扩展环间距和分区规则。
- **预计改善**：更多计算用于评价有效设计，扩大塔位/密度联合探索。
- **代价**：构造规则限制布局形状；公式若只保证名义相邻关系仍可能漏掉跨环最近对。
- **最小实验**：在相同镜数范围生成当前Q2-A与A0127式分区环带各20个几何候选，比较可行率、最近对分布和粗评价成本，再对各自前2名作全60较精评价。
- **放弃条件**：新构造不提高可行候选率或其最好粗评在复核中系统劣于当前生成器。

### M3：用A0165一维响应做预筛，不用它替代联合搜索

- **借鉴**：固定基线，分别扫描塔南移、统一宽度和环间距，识别有利区间和非单调性。
- **保留**：之后在有利区间内联合改变变量，并以额定门禁和完整评价确认。
- **兼容性**：现有参数化可直接生成切片候选；需共用随机数减少曲线噪声。
- **预计改善**：减少无依据的全范围搜索，发现变量尺度和交互方向。
- **代价**：切片响应依赖基线；若误认为全局单峰，会错过耦合改进。
- **最小实验**：每个变量5—7个点的全60低样本配对曲线，再挑2×2联合角点检查交互。
- **放弃条件**：响应噪声大于趋势、曲线强多峰或联合角点与单变量预测方向相反。

### M4：保留简单方法，压缩无收益复杂度

- **借鉴**：参考论文正文只呈现能解释结果的结构；完整日志留在证据层。
- **保留**：原始统计、失败和哈希，但由统一脚本自动生成索引。
- **预计改善**：把人工时间转回设计探索和关键消融。
- **最小验证**：下一题统计“决策性计算时间／机械记录时间”和因自动检查发现的问题数。
- **放弃条件**：压缩后无法重建关键结果或遗漏版本/失败关系。

## 6. 若只做一个后续实验

优先验证M1：在同一R027基线、同一评价器和同一随机流下，把Q3的6组表达扩展为按环10—20组，同时保留额定门禁和独立确认。

理由是：

1. A092最强的可识别结构差异正是逐环尺寸/高度，而不是已证实的GA优势；
2. 本解答逐镜参数接口已经存在，实施成本低于更换整个评价器；
3. 该实验直接检验“搜索表达过窄”这一最大疑点，并能用配对差值清楚评价收益；
4. 若仍无改善，就能把后续优先级转向镜位/塔位联合调整或评价口径消融，而不必继续猜测。
