# 盲测隔离规则

## 为什么只改文件名不够

赛题年份可能出现在文件名、父目录、PDF 页眉、PDF 元数据、Office 文档属性、下载压缩包名称和 Git 历史中。模型还可能通过同仓库中的年度目录和题目标题做关联。因此，本项目采用“匿名化 + 独立工作区 + 明确工具禁用”三层隔离。

## 本项目的隔离层

1. 匿名 PDF 删除首页比赛年份页眉，同时清空作者、创建日期和原始软件元数据。
2. 匿名附件使用通用编号，并清理 XLSX 核心文档属性。
3. 盲题使用随机编号，不按照年份排序。
4. 年份映射仅保存在本地 `tools/blind_mapping.local.json`，被 `.gitignore` 排除。
5. 单题通过导出工具复制到仓库外的独立目录，Codex 只打开该目录。
6. 盲解提示词禁止访问互联网、父目录、其他工作区和远程代码搜索。

## 仍然存在的局限

题目正文中的业务日期、政策背景、数据时间范围或技术热点可能让熟悉竞赛历史的人推断年份。机械删除这些内容会改变题意，因此不处理。实验记录中应把“是否猜到年份”单独列为污染检查项；如果模型主动声称识别年份，立即停止该次实验并更换题目。

## 盲解结束后的归档

管理员在模型停止工作后查看本地映射，把 `工作记录/` 移入相应的 `题库/题型/年份/解题过程/`，然后进入揭晓后复盘阶段。不要在盲解对话中展示映射。
