# 失败模式与禁止事项

| ID | 失败模式 | 为什么危险 | 自动/人工门禁 |
|---|---|---|---|
| AP-01 | 只检查目标中心或轴线 | 会把部分遮蔽误报为完全遮蔽 | 构造边界反例；输出最危险点 |
| AP-02 | 用无限直线相交代替线段相交 | 几何上会出现虚假可行 | 检查线段参数范围 |
| AP-03 | 固定时间网格直接当连续区间 | 起止时刻和短事件可能偏差 | 粗搜后连续求根；做容差收敛 |
| AP-04 | 重叠时长直接相加 | 高估多主体贡献 | 使用标准区间并测试 |
| AP-05 | 高维变量全部交给元启发式 | 搜索慢、不可解释且不稳 | 先做结构缩域、指派和初值 |
| AP-06 | 只展示最好随机种子 | 隐藏算法脆弱性 | 至少 10 种子并报告分布 |
| AP-07 | 优化器停止即宣称模型正确 | 数值收敛不等于物理正确 | 严格评价、第二路线、反例 |
| AP-08 | 非等间隔数据直接 FFT | 主频可能系统偏差 | 审计采样并重采样 |
| AP-09 | 为答案调滤波和频段 | 引入选择性偏差 | 参数预注册、消融和前后图 |
| AP-10 | 高 R² 当作参数无偏 | 尺度或物理模型仍可能错 | 残差、替代物理模型、合成回检 |
| AP-11 | 冲突模型结果直接平均 | 掩盖结构问题 | 查物理条件、残差和可辨识性 |
| AP-12 | 复杂模型参数多但无证据 | 过拟合且不可解释 | 信息准则、留出、参数相关 |
| AP-13 | 论文手工复制数字 | 摘要、正文、附件易冲突 | 唯一 results.json + result_id |
| AP-14 | AI 补写“合理”数据或引用 | 直接破坏诚信和可复现性 | 缺失填 null/UNVERIFIED |
| AP-15 | 历史题参数套入新题 | 题型和条件每年变化 | 历史包延迟解锁；来源标签 |
| AP-16 | 模仿优秀论文句式和结构细节 | 原创性、查重和锚定风险 | 只抽取质量标准，做语言相似审查 |
| AP-17 | 未核验当届 AI 规则 | 可能直接违规 | 合规状态未确认则 BLOCKED |
| AP-18 | PDF 只看源文件不逐页检查 | 公式、图表、分页可能损坏 | 渲染后逐页视觉检查 |

## P0 自动停机条件

出现以下任一情况，AI 必须停止标记“可提交”：

- 当届规则缺失或含糊且会影响 AI 使用；
- 题面、附件或模板读取不完整；
- 漏答分问或硬约束；
- 关键数字无实际运行证据；
- 严格评价器判定最终方案不可行；
- 引用无法核验；
- 正文和附件数字冲突；
- 历史数值进入当届结果；
- 文件含违反匿名要求的身份信息；
- PDF 或必交附件损坏。

## 失败必须转为资产

每次真实出现失败，至少完成一项：

- 新增单元或回归测试；
- 新增自动审计规则；
- 新增反例数据；
- 新增 AI 明确指令；
- 新增人工复核阈值；
- 更新方法卡的适用条件或失败触发；
- 更新论文审稿问题。
