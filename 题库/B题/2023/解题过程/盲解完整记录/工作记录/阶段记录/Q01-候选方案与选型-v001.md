# Q01 候选方案与选型 v001

## 1. 阶段目标

在第 1 问正式计算前，比较能够独立实现的几何路线，确定主模型、独立验证模型、坐标表示和相邻条带重叠率口径。前置依据为已验收的 S00、S01，以及已完成的 S02 方法学习。

## 2. 本轮获准的表示约定

| 项目 | 采用约定 | 性质与影响 |
|---|---|---|
| 水平原点 | 海域中心 | 表 1 的位置直接记为 $x_i$ |
| 水平正向 | 指向浅水、上坡侧 | $x_i$ 增大时水深减小；反向表示时结果应镜像 |
| 竖直正向 | 向上为正 | 换能器位于 $z=0$，海底高程为负 |
| 表 1 顺序 | $-800,-600,\ldots,800$ m | 有向“前一条”顺序固定 |
| 前一条测线 | 当前列左侧紧邻、先出现的测线 | 首列无前一条，保留破折号 |
| 开角 | $120^\circ$ 为总开角 | 半开角为 $60^\circ$ |
| 水深 | 换能器位置到海底的垂直距离 | 与坡面弧长和法向距离区分 |
| 坡度 | 海底剖面线与水平面的夹角 | 正坡度表示沿 $+x$ 高程上升 |

以上为本轮获准的表示约定，不声称是唯一坐标表达；任何完整反向都应给出同一物理几何的镜像结果。

## 3. 候选路线

### 3.1 候选 A：解析三角几何

在垂直于测线的二维剖面中，直接利用海底斜线与两条边界波束的夹角，推导下坡、上坡分覆盖宽度，再转为坡面覆盖区间。

- 优点：闭式表达短，量纲和参数依赖清楚，平坦极限易验证，适合论文正文。
- 风险：总开角与半开角、上坡/下坡符号、水平宽度与坡面宽度容易混淆。
- 控制措施：先固定坐标和测量方向，显式保留 $\cos(\beta+\alpha)$ 与 $\cos(\beta-\alpha)$ 两个分母，并做镜像检查。

### 3.2 候选 B：统一参数射线—直线求交

将海底写为一般直线，把中心波束和两条边界波束统一写为参数射线，逐条计算交点，再用交点坐标重建坡面区间。

- 优点：不调用手工推导出的分宽公式，能够直接检查交点参数、端点顺序和退化情况；以后改变角度或坡向时接口统一。
- 风险：若坐标系本身定义错误，程序仍可能给出内部一致结果；表达比闭式三角公式冗长。
- 控制措施：将其作为独立计算核对，并用平坦极限与坡度翻转避免解析模型和向量模型共享同一符号错误。

## 4. 候选比较

| 评价维度 | 候选 A：解析三角几何 | 候选 B：射线—直线求交 |
|---|---|---|
| 论文可解释性 | 高，能直接展示参数关系 | 中，需展开向量和参数 |
| 实现统一性 | 中，需分别处理左右分母 | 高，三条射线共用求交器 |
| 对角度符号的敏感性 | 较高 | 中等 |
| 退化域暴露 | 通过解析分母显式暴露 | 通过点积和射线参数显式暴露 |
| 与主公式的独立性 | 主路线 | 不使用主路线的分宽闭式，可独立核对 |
| 适合作为正式模型 | 是 | 可行但正文较重 |
| 适合作为验证模型 | 可做手算基准 | 是 |

## 5. 选型决定

- 主模型：候选 A，解析三角几何。
- 独立验证：候选 B，直接参数射线—直线求交并由交点计算区间。
- 未采用候选 B 作为正文主模型的原因：它对第 1 问的闭式关系表达不如候选 A 简洁；保留为独立验证能提供更高的信息增益。
- 未增加第三条路线：本问是解析闭式几何问题，两条路线已覆盖公式推导与独立实现；额外数值搜索不会提供新的有效证据。

## 6. 覆盖宽度口径

图 7 以两条边界波束在倾斜海底上的交点界定条带，因此正式覆盖宽度定义为坡面上两交点之间的实际长度。水平投影宽度等于该长度乘 $\cos\alpha$，仅作为辅助量，不填入表 1。

## 7. 相邻重叠率口径

对按表 1 顺序相邻的前一条带 $I_{i-1}$ 与当前条带 $I_i$，先计算：

\[
S_i=\min(R_{i-1},R_i)-\max(L_{i-1},L_i),
\]

\[
O_i=\max(0,S_i),\qquad G_i=\max(0,-S_i).
\]

其中 $S_i$ 为有符号重叠长度，$O_i$ 为实际集合交长，$G_i$ 为漏测间隙。正式表 1 采用：

\[
\eta_i^{\mathrm{prev}}=\frac{S_i}{W_{i-1}}.
\]

选择理由：

1. 分母与“前一条测线”的有向措辞一致；
2. 在平坦、等宽情形，$S_i=W-d$，严格恢复题面允许负值的 $\eta=1-d/W$；
3. 负值表示漏测，但实际交长 $O_i$ 始终非负；
4. 相比交并比，该口径不抹去题面给出的有向顺序。

主要备选口径为：

\[
\eta_i^{\mathrm{cur}}=\frac{S_i}{W_i}.
\]

另计算平均宽度归一值作为诊断。正式口径是第 1 问计算采用的基准解释，不声称为题面唯一可能的延拓定义。

## 8. 验证计划

1. 全 9 个位置逐项比较解析与独立求交得到的水深、端点、两侧分宽、总宽、有符号重叠和正式重叠率。
2. 用与正式输入无关的参数检查平坦极限。
3. 翻转坡度和坐标方向，检查水深镜像、端点镜像以及左右分宽互换。
4. 以分离、接触、部分重叠、包含和不等宽区间检查集合接口。
5. 检查量纲、适用域、单调趋势、Excel 数值类型和模板哈希。
6. 对前一条宽度与当前宽度两种分母做敏感性对照。

## 9. 阶段结论

候选比较与口径选择已完成。主模型和独立验证模型的计算路径不同，表示约定、覆盖宽度测量方向、前一条顺序、正式分母和备选分母均已明确，可连续进入建模求解。
