# 2025 A/B 案例解锁说明

本案例包只能在当届题目的独立 model_spec_v1 已经由人类确认并冻结后读取。

读取后只做四类比较：

1. keep：独立模型中应保留的正确结构；
2. upgrade：优秀案例提示但需要当届证据支持的增强；
3. reject：不适合当届题目的历史方法；
4. evidence_needed：采用增强前必须补做的实验或推导。

禁止：

- 导入 2025 数值、坐标、频段、材料参数和最优方案；
- 因为当届题号为 A/B 就套用相同题型；
- 复制独立论文或官方优秀论文的句子、段落、图表和代码；
- 用“官方案例采用”替代当届数据证据；
- 无理由推翻已经冻结的独立基础模型。

读取完成后输出 gap_analysis.json：

~~~json
{
  "schema_version": "1.0.0",
  "current_model_version": "model_spec_v1",
  "items": [
    {
      "current_component": "",
      "historical_pattern": "",
      "decision": "KEEP",
      "reason": "",
      "applicable_conditions": [],
      "required_evidence": [],
      "historical_values_imported": false
    }
  ],
  "attestation": {
    "historical_values_imported": false,
    "historical_text_copied": false
  }
}
~~~

合法的 decision 值：KEEP、UPGRADE、REJECT、DEFER。
