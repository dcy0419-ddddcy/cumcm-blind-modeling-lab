# 可移植复现说明

本材料包可以整体移动、复制或改名。验证入口只按自身所在目录解析文件，不依赖 `D:\2024` 或原工作区。

## 一键只读验证

在材料包根目录执行：

```text
python reproduce_pack.py
```

依赖至少为 Python 3.10、NumPy 和 SciPy；冻结 A 题环境记录为 NumPy 2.3.4、SciPy 1.16.3。若缺少依赖，可执行：

```text
python -m pip install -r 03_A题_独立成果/requirements.txt
```

入口会完成四项检查：

1. 对照 `06_审计/freeze_manifest.json`，逐个核验 A/B 冻结目录的 45 个文件哈希；
2. 运行 A 题 5 项几何、碰撞、调头与速度约束测试；
3. 运行 B 题 6 项抽样、受限策略枚举、问题 3 穷举和输出检查；
4. 检查三个 XLSX、B 题 `results/summary.json` 和三份最终 PDF 是否存在，共 7 件。

脚本不会重算并覆盖冻结结果，也不会在材料包中写入缓存。输出是一段 JSON；只有所有检查通过才返回退出码 0。

## 为什么冻结 README 仍出现旧绝对路径

`03_A题_独立成果` 与 `04_B题_独立成果` 是查阅官方案例前形成的只读历史快照，为保持哈希和独立性证据，未改写其中 README、测试导入名或旧工作区路径。根目录的 `reproduce_pack.py` 是后冻结新增的兼容层；它在内存中映射旧导入名，包移机后仍可验证原测试。

若要重新生成全部大体量 CSV/JSON，请先复制相应题目目录到新的实验目录，再按冻结 README 运行，避免覆盖历史证据。重新生成结果必须保留日志、环境、随机种子和新旧哈希，不得把未运行的结果标为已验证。
