# M05 数值误差、验证与复现

版本：v001；日期：2026-09-04。主线：Datawhale第3章§3.12随机模拟思想，原文片段见[D03](原文选段/D03-随机模拟基本思想.md)。下述条件化说明、误差分层和例子为管理员整理与推导；数值积分接口语义与SciPy 1.16.2官方文档核对。

## 1. 五种不确定性分开报告

| 类型 | 例子 | 能否靠增加计算量消除 |
|---|---|---|
| 输入不确定性 | 未知物性、测量范围 | 不能自动消除 |
| 模型偏差 | 忽略一种实际损失 | 不能自动消除 |
| 离散化误差 | 有限网格或求积节点 | 可能减小，但需收敛证据 |
| 随机误差 | 有限独立随机样本 | 条件满足时可减小 |
| 实现及舍入问题 | 坐标符号、分支、精度 | 需单测与数值稳定性分析 |

输出很多小数并不能解决任何一类模型不确定性。输入材料完整性检查也不等于模型验证通过。

## 2. 对随机模拟叙述的限定

原教程强调大量重复试验用频率估计概率。必须补充：样本来自正确分布、相应可积性及独立性或其他收敛条件满足时，才有对应保证。增加错误分布的样本只会更稳定地得到错误目标。随机积分估计与随机搜索最优值也不是同一件事；不能从“运行很多次”直接证明全局最优。

若\(X_j\)独立同分布且方差有限，样本均值估计\(\mu\)时：

\[
\widehat\mu_N=\frac1N\sum_{j=1}^N X_j,\qquad
\operatorname{Var}(\widehat\mu_N)=\frac{\sigma^2}{N}.
\]

因此标准差尺度为\(N^{-1/2}\)，不是每一次增加样本都单调更准确。伯努利例子的方差为\(p(1-p)/N\)；极端概率下不能盲目把观测方差为零当成确定无误。相关样本、加权样本需要另外分析。

## 3. 求积误差与收敛检查

对光滑函数的教学积分，可比较步长\(h,h/2,h/4\)的结果。若已进入误差形式\(C h^p\)的渐近区间，连续差值的比值可用于观察收敛阶；但两次结果接近，不证明绝对正确。边界不连续、窄峰或几何漏判都可能产生假收敛。

人工例子：在\([0,1]\)积分\(x^2\)，解析值为\(1/3\)。等宽复合中点法有：

\[
I_N=\frac13-\frac{1}{12N^2}.
\]

因此\(N=10,20,40\)时绝对误差依次为约\(8.3333\times10^{-4}\)、\(2.0833\times10^{-4}\)、\(5.2083\times10^{-5}\)。这只是教学例子，不是本题推荐网格数或误差容限。

SciPy的 `quad` 返回积分与绝对误差估计；`epsabs` 和 `epsrel` 控制尝试达到的绝对、相对精度，不能把返回的误差估计当作物理模型偏差或无条件严格误差上界。本包不依赖SciPy运行，不安装求解器。

## 4. 最小验证层级

1. 单位与维度：先判断公式两边量纲是否一致。
2. 代数性质：常量保持、概率归一、守恒和旋转不变量。
3. 解析小例子：用独立于目标数据的已知答案测试。
4. 边界与反例：零输入、平行、共面、零分母、极小角。
5. 独立交叉核对：不只比较共享同一错误公式的两个程序。
6. 离散化或重复试验：分别观察偏差与随机波动。
7. 输入敏感性：仅在参数范围有依据和阶段获准时进行。

数值容差的通用形式可以写为：

\[
|a-b|\leq \varepsilon_{\mathrm{abs}}+
\varepsilon_{\mathrm{rel}}\max(|a|,|b|).
\]

具体数值必须依据量纲、尺度和用途决定。测试脚本为通用例子的机器检查设置的容差，不得当作本题精度批准。

## 5. 复现清单

保存输入版本及哈希、代码版本、配置、解释器与库版本、运行目录和命令、随机数生成器与种子、输出、失败和重试信息。使用随机数时固定种子有助复跑，但不保证跨库版本位级一致，也不证明不确定性已经量化。

所有改动保留原结果、原因和受影响的下游接口。对失败的测试先记录观察，再区分确定原因与待检验猜测，不删除旧证据以获得“全绿”。

本包的检查脚本使用Python标准库，仅处理文中人工常数，不访问网络和题目数据；它验证教学关系，不是本题求解程序。
