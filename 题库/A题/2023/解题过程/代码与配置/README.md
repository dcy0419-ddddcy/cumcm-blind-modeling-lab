# 代码与配置入口

本目录保存盲解阶段实际使用的材料审计、几何评价、全场计算、布局参数化、搜索、独立确认、汇总重建、论文生成与交付核验代码。

主要系列：

- q01_core、q01_full_run、q01_full_summary：第1问物理核、完整评价和汇总；
- q02_design、q02_parametric、q02_search、q02_repair：第2问参数化、搜索和可行性修复；
- q03_design、q03_eval、q03_search、q03_confirm：第3问异尺寸评价、分组搜索与确认；
- s03系列：全题整合、来源绑定和冻结候选核验；
- verify系列：文件、链接、版本和证据映射检查。

历史版本和修订前版本保留，用于解释失败和接口变化。当前执行入口应结合阶段记录、配置哈希和结果生成谱系判断，不能仅以文件名版本号猜测。
