# 归档清单生成说明 v001

## 生成入口

在工作区根目录运行：

`python 工作记录/揭晓后对照/最终方法与创新总结-v001/build_archive_manifest_v001.py`

脚本只读取本工作区现存文件并生成CSV/JSON，不读取Git历史、工作区外目录或网络。为避免自引用，输出的CSV和JSON不纳入自身清单；生成脚本和本说明纳入清单并有SHA-256。

## 字段解释

| 字段 | 含义 |
|---|---|
| `relative_path` | 相对本题工作区的路径，便于仓库映射 |
| `bytes`、`sha256` | 文件字节数和内容校验值 |
| `stage` | 按路径和文件名确定的阶段类别 |
| `identity` | 盲解/项目公共或揭晓后材料 |
| `validity` | 当前入口、冻结字节、历史失败证据或需结合索引判断 |
| `archive_category` | 文档代码证据、大文件、第三方材料或可重建产物 |
| `dependency_or_inclusion` | 当前工作区是否包含，或是否存在许可依赖 |
| `recommended_action` | 建议入库、另行存储、许可判断或管理员判断 |

## 限制

自动分类不替代`工作记录/记录索引.md`中的人工版本关系。文件名含“首次”“失败”“before”等标志时会被保守标成历史证据；版本化文件的当前性默认要求管理员结合索引核对。第三方材料只按已知目录识别，再分发许可必须人工判断。
