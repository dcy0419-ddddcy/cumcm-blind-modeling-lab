# 可复用建模方法卡

> 仅在独立 model_spec_v1 冻结后读取。方法卡按适用条件调用，不按下一届 A/B 题号调用。

## CARD-GEO-01：严格几何评价器

- 适用：视线、覆盖、碰撞、可达、遮挡和安全距离；
- 输入：运动状态、几何对象、时间、边界；
- 核心：把条件写成带符号裕度，并区分直线、射线与线段；
- 先证明：只需检查哪些边界或极值点；
- 再数值：报告边界采样收敛；
- 输出：可行布尔值、最小裕度、最危险点、违规原因；
- 反例：中心满足但边界不满足；直线相交但线段不相交；
- 论文证据：几何图、推导、伪代码、反例、收敛表。

## CARD-EVENT-01：连续事件与区间并

- 适用：有效持续时间、进入/离开区域、超过阈值的时间；
- 方法：粗网格定位真假切换，用二分/Brent 求根；
- 目标：使用事件区间并集，不能直接相加；
- 测试：空集、相接、重叠、包含、端点和多个不连续区间；
- 误差：时间容差与目标值误差分开报告；
- 论文证据：时间轴图、边界求根容差、固定网格对比。

## CARD-OPT-01：结构化高维优化

- 适用：混合离散连续、多智能体、多阶段；
- 顺序：物理/几何缩域 → 快速初值 → 离散指派 → 连续精调 → 严格重算；
- 评价器：所有算法共享唯一严格评价器；
- 稳定性：至少 10 个随机种子，报告分布而非只报最好值；
- 复核：第二算法或解析构造；
- 禁止：直接把全部变量交给元启发式后称全局最优。

## CARD-SIGNAL-01：可信预处理

- 适用：非平稳背景、尖峰、噪声、非等间隔采样；
- 步骤：排序/去重 → 单位 → 等距重采样 → 去趋势 → 去尖峰 → 适度平滑；
- 每步保存参数和前后图；
- FFT 前必须确认采样变量等间隔；
- 选带同时考察主频稳定性、SNR 和物理适用区；
- 消融：改变窗口、平滑和边界，检查主结果稳定性；
- 禁止：为获得期望结果调滤波但不报告。

## CARD-INIT-01：双快速初值

- 适用：周期信号参数估计；
- 路线 A：FFT 或自相关；
- 路线 B：峰序、极值间距或相位展开；
- 采用：两者接近时作为全模型初值；
- 冲突：差异超过预设阈值时先查采样、峰选取、色散和多频成分；
- 禁止：直接平均冲突初值。

## CARD-INVERSE-01：多数据集联合反演

- 共享：真实物理参数；
- 分组：角度/批次的幅值、基线、小校准；
- 目标：鲁棒损失 + 物理边界 + 适度先验；
- 降维：可闭式求解的线性参数放内层，非线性参数放外层；
- 初值：来自快速模型；
- 审计：单独拟合与联合拟合、参数相关、轮廓似然、bootstrap；
- 失败触发：参数贴边、多个等价最优、残差保留结构。

## CARD-MODEL-01：简单与复杂模型选择

- 先运行可解释基线；
- 记录基线在哪种残差或物理条件下失败；
- 复杂模型必须改善留出误差、残差结构或信息准则；
- 新增参数必须可辨识；
- 结果应对初值、频段和先验不过度敏感；
- 未通过时回退基线并说明局限；
- 不能因为复杂模型拟合更好就自动采用。

## CARD-VALID-01：双证据验证

核心结论至少选两类独立证据：

- 手算/解析；
- 收敛；
- 第二算法/模型；
- 多种子；
- 反例/边界；
- 残差/残差频谱；
- 多批次一致性；
- 参数不确定性；
- 灵敏度；
- 合成数据恢复。

冲突必须定位，不能平均掩盖。

## CARD-PAPER-01：结果驱动论文

- results.json 是唯一数字源；
- 摘要每问写模型、数字/单位和验证；
- 正文每问闭环：目标—变量—方程—约束—算法—结果—验证—解释；
- 图表由代码生成并回答明确问题；
- 所有引用真实可核验；
- 历史范文只用于质量对标，不用于措辞模仿；
- PDF 逐页视觉检查；
- 最终执行数字一致性和匿名/规则审计。
