# 通用教学例子的离线验证

版本：v001；作者：资料管理员；许可：CC BY-NC-SA 4.0。

脚本：[check_examples.py](check_examples.py)。结果：[管理员运行结果](运行结果-v001.json)。

## 范围

只检查M01至M05中的人工常数例子：质量守恒、主动/逆旋转、单位长度、理想反射、平面交点、条件能量比、损失并集、教学圆锥归一和余弦期望、平均乘积/比值反例、两级平均、中点求积收敛、固定种子复跑。

没有使用题目PDF、附件、镜位、时间表、工程功率或候选光源角尺度。教学圆锥角度仅用于演示一般积分，不是建议物理值。测试通过不能写成本题验证通过。

## 运行

依赖：Python 3标准库，无需NumPy或SciPy，无需网络或安装。进入本目录后执行 `python check_examples.py`，结果输出到标准输出，退出码0表示这些检查全部通过。脚本本身不读写文件、不读取网络和凭据。

管理员使用本机预装Python 3.12.14执行，版本与平台写在结果JSON中。随机数只用于固定种子可重复性的演示；生成器为 `random.Random`，种子731。该随机检查不估计本题误差。

对照JSON中的每个名称可以追溯对应方法卡章节。机器容差仅服务于这些教学恒等式与近似积分，不得作为实际模型的批准容差。
