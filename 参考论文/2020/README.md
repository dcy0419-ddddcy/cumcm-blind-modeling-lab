## 论文版权与训练隔离

中国大学生在线的论文展示页面明确标注未经竞赛组委会书面许可不得转载，因此这里不复制页面图片、不拼接论文 PDF，只保存官方直达链接和客观元数据。

进入 2020 年任一题的盲解阶段时，不得把本目录交给模型。只有在盲解结果冻结后，才允许读取相应题目的优秀论文入口进行复盘。
