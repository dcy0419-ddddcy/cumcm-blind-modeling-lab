## 范围与文件来源

1. 官网 A、B、C 三个子栏目当前分别返回 1、2、2 条记录，共 5 篇；这是官方公开展示集，不代表全部获奖论文。D、E 题不在本次本科组整理范围内。
2. 赛题及附件逐字节复制自本仓库 `题库/A题/2025`、`题库/B题/2025`、`题库/C题/2025`。只在参考目录内展平重复的附件目录层级，不改写 PDF 或附件内容。
3. `result1.xlsx`、`result2.xlsx`、`result3.xlsx` 是题目配套结果表，不是优秀论文答案。
4. 原主题库、已归档解题记录、经验文档均保持不变。

## 使用阶段

- 可用于赛前表达规范与通用方法学习，借鉴时应标注来源。
- 如仍需盲解 2025 年对应题目，应在盲解版本冻结后才读取这些论文。
- 模型已经读取对应论文后，应把同题实验标为参考辅助训练，不再视作独立盲测。
