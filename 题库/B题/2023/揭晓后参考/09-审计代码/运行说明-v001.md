# 揭晓后审计代码运行说明 v001

## 适用范围

这些脚本只用于冻结、材料提取、数值对照和只读验证。它们不覆盖盲解工作区文件，不替换四问结果，也不构成新的正式求解。所有输出均位于“揭晓后参考”目录。

## 环境与随机性

- 操作系统：Windows，PowerShell。
- Python：系统可用Python；官方页图OCR使用 `09-审计代码/.venv-ocr` 中的本地环境。
- Node.js与工作簿读取库：使用Codex桌面提供的工作区依赖；工作簿脚本为只读。
- 本轮核心复算均为确定性运算，无随机种子。以后若运行元启发式优化，不属于本说明范围。

## 推荐运行顺序

1. 只在联网前首次运行冻结清单生成脚本；后续不得重新生成并覆盖基准清单。
2. 运行工作簿只读检查，确认四个结果工作簿可被独立读回。
3. 在冻结核验通过后，才运行下载与OCR脚本。
4. 完成逐篇提取后，运行四问数值对照。
5. 运行高分辨率反例检查；将发现写入二次复核，不回写盲解文件。
6. 全部复盘文档完成后再次运行冻结核验脚本，确认核心文件哈希仍与联网前清单相同。

## 典型命令

在PowerShell中进入 `揭晓后参考` 后，可按需执行：

```powershell
powershell -ExecutionPolicy Bypass -File ".\09-审计代码\核验盲解冻结-v001.ps1"
python ".\09-审计代码\四问数值对照-v001.py"
python ".\09-审计代码\冻结方案高分辨率复核-v001.py"
```

下载脚本会访问互联网，只有揭晓后复盘且已通过冻结核验时才可运行。OCR与高分辨率检查可能耗时较长；它们不应被用于覆盖原始论文或冻结结果。

## 复现注意事项

- 相对路径均以 `揭晓后参考` 为基准。
- PDF合订是原官方页图的容器转换；原图、页序、下载URL和SHA-256另存，OCR不作为关键数值的最终证据。
- 第2问64格对照先做方向语义对齐，再计算绝对误差；不能把镜像或方位变换混为数值错误。
- 第4问复核必须保留开角、地形表示、采样间距、网格相位、足迹模型和超限统计对象；缺少任一项，结果不可与其他论文直接比较。
- SHA-256只证明文件字节是否改变，不证明模型内容正确；内容正确性由解析推导、独立实现、参考对照和反例测试共同支持。
